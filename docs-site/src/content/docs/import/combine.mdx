	- A client sent revisions as separate files that all belong in one packet.

## Steps

1. Import every file you want in the final document (drag them in, or <Kbd>⇧⌘O</Kbd>).
2. In the sidebar, drag whole documents up or down to set their order in the combined export. Expand a document to drag its pages into a new order within that same document.
3. Delete or rotate any pages you don't need.
4. Export once as a single PDF.

   <Figure src="/Orifold/assets/gifs/combine-reorder-pages.png" alt="Three documents in one workspace's sidebar, each expanded to show page thumbnails that can be reordered within their own document." caption="Order whole documents for the combined export, or reorder pages within the document they already belong to." />

<Callout variant="tip">
	Merging isn't a separate step in Orifold — the workspace *is* the merge. Arrange the documents, and reorder pages within each document when needed, then export once.
</Callout>

## What you should see

One exported PDF containing every imported document in the document order you arranged, with each document's pages in its own arranged order.
