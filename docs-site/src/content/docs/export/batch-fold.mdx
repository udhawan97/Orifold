## Fold the stack

1. Choose **File → Fold a Folder…**.
2. Choose one or more steps: make scanned pages searchable, add a watermark, or reduce file size.
3. Pick the folder containing the PDFs.
4. Start the fold and follow the per-file progress. You can cancel between files.

Choose a preset to populate the same controls in one step:

- **Searchable copies** turns on OCR.
- **Smaller copies** uses balanced compression.
- **Review copies** adds the standard localized **Draft** watermark and balanced compression.

Presets never start a job. You can adjust every populated control before choosing a folder.
Orifold can remember one **My preset** configuration; saving it stores only the OCR toggle,
compression level, and standard-watermark choice. You can replace or delete it from the same
sheet. Custom watermark wording applies to the current run only and is never saved.

Orifold applies selected work in the order **OCR → watermark → compress**, then validates each
PDF before saving it. When the run ends, a results sheet keeps one row for every PDF Orifold
planned to process: completed, failed, cancelled while processing, or not started. One unreadable
file is reported as one failure; it does not discard the successful files around it. You can
filter the report, reveal individual outputs, or open the output folder. Dismissed results remain
available from **Fold a Folder… → View Last Results** until the next run or window close.

If you cancel, completed outputs stay completed and files Orifold did not reach are labelled
**Not started**. If the folder scan reaches its safety limit or cannot read part of the folder,
the report says its counts are incomplete instead of treating undiscovered files as processed.

## Where results go

Results land in a `Folded` subfolder beside the originals. Existing names are disambiguated
case-insensitively. If another app creates the chosen output name while a PDF is being processed,
Orifold keeps that file untouched and chooses another name. Source PDFs and earlier outputs are
never replaced. A later run skips the `Folded` subtree, so generated outputs are never folded
again as new inputs.

<Callout variant="note">
	The batch uses the same local engines and structural postflight as the single-document tools.
	No PDF or recognized text is uploaded.
</Callout>
