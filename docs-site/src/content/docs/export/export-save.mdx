## Steps

1. Click **Export** in the toolbar, press <Kbd>⌘E</Kbd>, or choose **File → Export**.
2. Choose a format: PDF, DOCX, Markdown, plain text, HTML, PNG pages, or JPEG pages. Printing remains in **File → Print** or <Kbd>⌘P</Kbd>.
3. For PDF, optionally turn on password protection, file-size reduction, sanitize-for-sharing, or an imposition layout. The extra settings appear directly below the option you enabled.
4. Pick a location in the save panel and confirm — Orifold asks where the file goes before it starts any work.

<Callout variant="note">
	Password protection, file-size reduction, sanitize, and imposition all run after you've chosen the destination, with a progress indicator and a working **Cancel**. The window stays responsive while they work.
</Callout>

## Where did my file go?

Exactly where you chose in the save panel — there's no hidden folder or upload step. If you're not sure where you saved it, check the location shown in the save dialog before you clicked Save, or search Spotlight for the filename.

<Callout variant="note">
	**Why it matters:** PDF output is structurally checked before publication. That check does not establish the correctness of every form answer, attachment, visual edit, or reading order. If export fails, see [Export & save problems](/Orifold/help/troubleshooting/export/).
</Callout>

## What you should see

A new file at the location you chose, in the format you picked, which you should reopen to confirm the content and layout you need.

## Output and cancellation boundaries

PNG and JPEG page exports stage their output and publish it as a folder transaction. Replacing
an existing destination preserves the previous result until the staged set is ready; a failure
should leave no partial published set. Inspect the final folder rather than a progress label.

Cancellation is checked before a print handoff or final publication. Once the system print
panel or a completed file handoff owns the operation, use that surface’s controls. Saved
multi-page layout selection is restored with the workspace; verify the chosen layout and
preview before printing or exporting.
