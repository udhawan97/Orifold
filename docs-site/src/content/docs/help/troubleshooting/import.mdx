## A PDF won't import or shows as corrupted

Orifold attempts a qpdf recovery pass automatically for damaged PDFs. If recovery still fails, the file's internal structure may be too badly damaged to repair — try opening it in another app first to see if it opens at all.

## I've hit the 50-file import batch limit

Orifold accepts up to 50 files per import batch. Wait for the current import to finish, then use **Add Files** again to select the remaining files and add them to the same workspace.

If a folder contains more than 50 supported files, Orifold offers to import the first 50. Select the remaining files in later batches; importing the same folder again can add duplicates. Very large folder scans can also be truncated, with a warning that some files were skipped. Choose smaller subfolders or select the skipped files with **Add Files**.

## An imported file doesn't show any content

Confirm the format is supported: PDF, Word and OpenDocument text, HTML, Markdown, plain text and source files, CSV, JSON, XML, spreadsheets, presentations, EPUB, SVG, common images, and CBZ comic-book archives. Other formats aren't recognized yet.

## A CBZ comic will not import

A CBZ must be a readable ZIP-compatible archive containing supported image files. Orifold ignores folders, text files, and macOS metadata; it reports a specific error if no image pages remain. Archives over 100 MB, individual expanded entries over 25 MB, or comics over 1,000 image pages are refused rather than partially converted.

## The password prompt keeps reappearing

Double-check you're entering the PDF's actual open password, not a permissions/owner password — some PDFs use different passwords for opening versus editing permissions.

## Large files feel slow

Very large scanned PDFs (hundreds of high-resolution pages) can take longer to render and OCR. This is expected — everything is processing locally, with no cloud offload to speed it up.
