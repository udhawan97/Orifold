## Requirements

macOS 14 Sonoma or newer, on Apple Silicon **or** Intel — Orifold ships as a universal build, so one download works for both. The prebuilt app needs no Xcode or GitHub account. Source builds require a development toolchain.

## Steps

1. Open **Applications → Utilities → Terminal**.
2. Paste this and press Return:

   ```zsh
   curl -fsSL https://raw.githubusercontent.com/udhawan97/Orifold/main/install.sh | zsh
   ```

3. The installer downloads the prebuilt app to `~/Applications/Orifold.app` and adds two helpers to your Desktop: **Orifold.command** (launch + auto-update) and **Uninstall Orifold.command**.

<Callout variant="tip">
	The installer downloads a prebuilt app and clears its quarantine. Review the script first if desired. The manual DMG route below keeps macOS’s normal first-launch approval flow.
</Callout>

### If macOS warns about an unidentified developer

Public builds are ad-hoc signed and not Apple-notarized unless the release says otherwise. Verify the source and checksum, then follow [Apple’s first-launch guidance](https://support.apple.com/en-us/102445) if macOS blocks opening it.

## Prefer Homebrew?

```zsh
brew tap udhawan97/orifold https://github.com/udhawan97/Orifold
brew install --cask udhawan97/orifold/orifold
```

This installs the same prebuilt app and clears the download quarantine automatically. The cask is stored in this repository; the explicit `brew tap` URL above is required on a fresh setup. It uses `version :latest` and `sha256 :no_check`, so compare important downloads with the published manifest. The one-line installer also creates the Desktop helpers.

## Prefer a direct download (DMG)?

Download the disk image — [`Orifold.dmg`](https://github.com/udhawan97/Orifold/releases/latest/download/Orifold.dmg) (universal: Apple Silicon + Intel):

1. Open the downloaded `Orifold.dmg`.
2. Drag **Orifold** into the **Applications** folder.
3. Open Orifold from Applications.

If macOS blocks first launch, first confirm the download came from the official release and matches its checksum. For an unverified-developer alert, [Apple documents the per-app approval flow](https://support.apple.com/en-us/102445). A damaged or malware alert needs investigation; do not assume it is just quarantine.

<Callout variant="tip">
	The Terminal installer and Homebrew cask clear download quarantine. This changes the first-launch check; it does not establish notarization or guarantee a dialog-free installation. The ZIP remains available for these paths.
</Callout>

You can verify a download against its published checksum:

```zsh
shasum -a 256 ~/Downloads/Orifold.dmg
```

Compare the result to the checksum in the release's `manifest.json`.

## What you should see

The Terminal installer places `Orifold.app` in `~/Applications` and creates Desktop helpers. The DMG and Homebrew paths usually place the app in `/Applications` and do not create those helpers.
