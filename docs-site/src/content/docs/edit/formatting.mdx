## Steps

- **Keep existing formatting** — edit detected text and choose **Done** without changing the toolbar. Its detected font family, size, traits, underline, color, alignment, line spacing, and paragraph or column geometry remain the starting format.
- **Match formatting** — select an edit or text box and choose **Match** to apply the nearby format Orifold already detected. Existing text adopts that style and paragraph geometry; an inserted text box keeps the placement you chose.
- **Copy formatting** — copy the style from one edit or text box to reuse on another.
- **Paste formatting** — apply a copied style to the selected edit or text box without moving it.
- **Reset formatting** — restore an edit or text box to its initial inferred format, or to Orifold's default when no nearby format was detected.

## What you should see

The selected text updates immediately. Existing text keeps its original source format unless you explicitly apply a different one. When a source font is unavailable, Orifold uses a metric-compatible substitute to keep the replacement close to the original spacing and margins.
