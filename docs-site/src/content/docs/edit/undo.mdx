<Callout variant="whentouse">
	You deleted, rotated, or edited something and want it back.
</Callout>

Press <Kbd>⌘Z</Kbd> to undo and <Kbd>⌘Y</Kbd> to redo. This covers page deletes, rotations, text edits, object moves and resizes, object style changes, and annotations.

While an inline text editor is open, undo and redo apply only to your typing. If that local history is exhausted, Orifold leaves workspace history untouched and tells you there is nothing more to undo or redo in the editor. Choose **Done**, **Cancel**, or close the editor before using the same shortcuts for committed text, object, page, and annotation operations.

<Callout variant="tip">
	Undo is fearless here — experiment with reordering and deleting pages, knowing you can always step back.
</Callout>
